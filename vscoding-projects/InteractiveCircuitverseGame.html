🧠 Hacker's Codex

Boolean Algebra Basics:

  • A + A = A
  • A * A = A
  • A + 1 = 1
  • A * 0 = 0
  • A + A' = 1
  • A * A' = 0

K-Map Tips:

  • Group 1s into rectangles of 1, 2, 4, or 8
  • Only powers of two are allowed in a group
  • Minimize the number of groups
  • Use don't-cares (X) to help reduce complexity
  • Note the Gray code ordering (00, 01, 11, 10)

Example:
Expression: A*~B + C
Simplified: A̅ + C
